# Backend packages

`fannagent` ships the synthetic `fake` descriptor only. `fannagent-pgvector` registers pgvector through API v1. Use `fannagent backends list` and `describe NAME` for installed identities, schemas, profiles and qualification limitations. Read [EXTENSIONS.md](EXTENSIONS.md) to add a backend in a separate distribution.

Weaviate and Elasticsearch/Lucene are TODOs. Their historic inspectors in `deferred/` are unshipped references. Future packages must demonstrate complete support against an unchanged compatible core wheel; no empty packages are published.
