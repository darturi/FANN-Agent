## Where activation time goes

The frozen Light19 seed sends unfiltered and `votes32` requests through the policy and `votes108` through ordinary native SQL. The constructor runs composite admission before it sees the query. Both routes pay policy validation, an ownership copy, identity construction and query normalization. Only the eligible route normalizes the query again inside the backend and hands the tree to the prepared cache, which validates, copies and serializes before looking up the key. First use also pays lazy compilation and acknowledged server installation inside the backend timer. ## What would justify a run

An early bypass could defer tree admission until a validated eligible request. That design would need to preserve invalid-input behavior, predicate and vector semantics, connection binding, and the distinction between genuine bypass and failed policy execution. A single preparation step on the eligible route could pass a private validated artifact into backend execution and eliminate duplicate work. P2a already removed repeated backend preparation on reuse while keeping first preparation and installation charged. P2c measured 0.171 ms activation savings versus original execution for the combined P2 path in its conditioned comparison, and that path still lost to its own native reference on activation. The saved profiles identify repeated work but cannot price its removal on first use or isolate the separate installation cost from database and transport wait. [P2a results](fannagent-prepared-policy-lifecycle-v1-results-2026-10-23.md) · [P2c results](fannagent-activation-timing-calibration-v1-results-2026-10-24.md)

Reopen for a specific, semantics-preserving change with evidence that it can materially reduce **eligible first-use cost inside the backend timer** as well as composite admission. Freeze one candidate and compare it to the original native path with full activation charges and unchanged controls. Proceed to recall and reuse qualification on the same artifact only if the activation screen passes. Independent confirmation requires a joint development pass and a valid separate entitlement. A3 and the partial index are outside this dependency chain.
