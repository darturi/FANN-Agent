This project investigates whether an AI agent can learn useful patterns about the shape of a database's data from past query executions and use that knowledge to make future queries more efficient. The initial case study focuses on filtered approximate nearest-neighbor search, in which a system must find the vectors most similar to a query while also satisfying a metadata condition. The difficulty of these searches depends not only on how many records satisfy the filter, but also on how those records are distributed within the vector space. By observing search behavior and a limited number of exact results, the agent will construct a compact, inspectable model of relationships among query neighborhoods, filter membership, and search progress. It will then use this model to generate a lightweight policy that decides whether an ongoing search should continue or stop. Keeping the execution decision limited to stopping makes it possible to evaluate whether learned structural knowledge improves search efficiency without changing the underlying index or traversal algorithm. The generated policy will run without requiring a language-model call during each query and will be evaluated on unseen queries for retrieval quality, execution cost, and evidence efficiency. More broadly, the project explores whether databases can accumulate reusable knowledge about their own data through query experience, providing a foundation for later work on structure-aware query planning, traversal, indexing, and physical design.
