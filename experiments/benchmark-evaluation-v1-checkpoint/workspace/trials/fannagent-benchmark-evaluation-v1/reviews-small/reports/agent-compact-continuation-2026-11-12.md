# Compact evidence and bounded evaluator continuation

The authorized continuation produced three distinct policies that pass exact saved-output replay on all 3,150 development cases: zero per-query recall losses against guarded native640, all seven conditions at or above .95 mean recall. These are candidates pending compilation, live qualification and complete serving-time measurement. No final policy has been selected and validation/test outcomes remain unopened.

## Method and boundary

The original first-request abstention remains recorded unchanged. The user authorized a versioned method continuation using only the two remaining requests within the original three-request/$15 allowance. The compact evidence is 52,996 bytes: fixed per-filter/checkpoint bins, safe/lossy extrema and deterministic examples drawn exclusively from the same 450 development groups. Bin boundaries were fixed before dispatch, without a host threshold search. No text, vectors, original query/result IDs, credentials or holdout cases entered the payload.

Request2 could invoke one bounded evaluator batch with at most three model-authored causal JSON policies. The evaluator exposed no shell, SQL, arbitrary code, external network or holdout access. It replayed all development records at original feature precision and returned per-filter/fold metrics plus at most three counterexamples per condition. Request3 received that feedback and could author up to three final programs. Exactly one tool call was requested and executed. All six scalar filters plus unfiltered remained in every replay; omitted policy branches continue through the unchanged guarded native parent. The shared completion guard, graph, checkpoints, recall/completeness rules and frozen split were unchanged.

The final response included prose followed by exactly one JSON fenced block, which the original strict parser rejected. The raw response and initial rejection are retained. A separately recorded envelope recovery extracted that single JSON object and validated its unchanged programs. It did not edit any threshold or make another provider call. The original and reconciled summaries coexist; use `reconciled-summary.json` and `continuation-verification.json` for the final disposition.
