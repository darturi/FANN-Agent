# Uncertainty-aware M5 shortlist contract v1

November 16, 2026. Authorized implementation and qualification after M2's published negative
results. All M1/M2 aggregates and six diagnostic programs are already exposed. This adapts the
method using that evidence; no new clean holdout, future-query guarantee or independent
confirmation is claimed. The earlier precision qualification remains FAILED and immutable.

## Fixed evidence, predictor and support

Use the existing 450 development groups, all six scalar filters plus unfiltered, complete
9,436 actual prefix labels, frozen folds and measured prefix work. Exact labels are offline
scoring only. No new SQL search, provider request or protected outcome access is needed.

Reuse M2's signed additive proxy without refitting any coefficients. Each group's coefficient
set is the existing model fitted without that exposed query fold. Bare-prefix calibration
bases are the existing same-block ratios. Keep every signed increment. Convert to a primary
ratio using one declared reference scale: block3 native per-group/filter means. This is an
evaluator proxy ratio, not measured latency of a new program. Never pool native blocks.

Support requires the qualified DSL/profile and complete per-group prefix inputs; every
predicate/checkpoint mask must occur in M1's compiled pool. Per-group/checkpoint numerical-test
counts must not exceed the maximum among the 11 fixed calibration probes, including null and
short-circuit behavior. All per-query predicted totals must be finite and positive. Unsupported
programs retain quality/work feedback but cannot be nominated through this contract. No cost,
ID, group, fold, work or truth field becomes a compiled policy feature.

## Engineering error envelope and its qualification

Evaluate the unchanged predictor against the six excluded M2 transfer/matched-control programs
using their own measured block native ratios. Include primary, all seven condition, five
exposed fold, four physical CPU and two cycle ratios. Include the endpoints of the 20,000-draw
conditional primary signed-error bootstrap interval, seed20261116, preserving group pairing.
The predictor's reference weighting and the target's same-block weighting remain explicit.

For calibration set C, fix one global radius
`r(C) = 0.01 + max(abs(error) for every declared diagnostic in C)`.
The one-native-percentage-point guard equals the original shortlist tie tolerance. This is an
empirical engineering envelope, NOT a 95% prediction interval or a claim of coverage for future
programs, queries or allocations. Signed/negative errors are retained. Apply the same radius
to primary and every per-filter estimate, keeping all six filters in the objective.

Three outer checks each exclude a COMPLETE policy/control pair (Conservative, Moderate, Broad).
Calibrate only on the other two pairs; require every excluded point diagnostic and its primary
bootstrap error interval to lie within the calibrated radius. No excluded pair calibrates its
own radius. Require every outer radius and the final all-pair deployment radius <=0.05.
No increasing the guard, dropping a diagnostic or trying another envelope after seeing results.
This excludes vacuous unbounded intervals while retaining explicit adaptation to known M2 data.

Deploy the all-pair radius only if every outer check passes. Positive/negative model precision
status is unchanged. Costs have a new status: qualified only for this conditional experimental
shortlist contract. No automatic additive-model accuracy or final performance claim is made.

## Shortlist decision and conditional certificate

Deduplicate canonical policy hashes; invalid/duplicate submissions still consume the original
quotas. Eligible M5 nominees require zero per-query raw-native recall losses, complete proofs,
supported uncertainty estimates and at least one actual early stop on a scalar condition.
No-stop controls remain reported; native is an available final comparator/abstention.

Let each admissible nominee have interval [L,U]. Enumerate every subset S of size0..3 among
at most9 submissions. Native at normalized cost1 is available alongside each S. Its conditional
oracle-measurement regret bound is
`max(0, min(1, min(U_i for i in S)) - min(1, min(L_j for j not in S)))`.
An empty min contributes1. The selected and excluded identities are kept separate, so selecting
all nominees has regret0. The formula assumes costs lie in the engineering intervals and M5
can identify the best measured alternative; it does not include future allocation/measurement
noise or guarantee final selection quality.

Accept only subsets with bound <=0.01. Prefer the fewest live nominees, then smaller bound,
then fewer total comparisons, fewer total clauses, sorted rule hashes. Point estimates never
break an overlapping-interval tie. Empty S is certified native abstention when it meets the
bound. If no subset meets the bound, explicitly abstain for insufficient discrimination within
the three-finalist cap. Do not arbitrarily choose three from a larger ambiguous set, raise the
cap, fit thresholds, or request more model rescue rounds. A nominal request's candidate IDs
must equal the deterministic result.
